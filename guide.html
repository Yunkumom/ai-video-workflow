01 · Setup 環境設定

Prepare the tools below for the full local workflow. Check items manually after setup.
完整本機流程需先備妥以下工具；安裝後可手動勾選，不代表自動偵測。

Tools 本機工具

Install & verify 安裝與檢查

With Homebrew installed:
已有 Homebrew 時執行：

brew install python ffmpeg
# Optional downloads / 選用下載工具
brew install yt-dlp
# macOS build tools / macOS 建置工具
xcode-select --install
python3 --version
ffmpeg -version
ffprobe -version
swiftc --version
yt-dlp --version

Homebrew · FFmpeg · yt-dlp

Groq · AI 服務

Create an account and an API key for speech transcription.
建立帳號並取得 API 金鑰，用於語音辨識。

Get API key 取得 API 金鑰 ↗

Restart after configuration. This app does not load .env automatically; never paste a key into this guide.
設定後重新啟動。現有程式不會自動讀取 .env；請勿將金鑰貼在本指南。

“PG” is unconfirmed. PostgreSQL is not required by the current launcher; ffprobe comes with FFmpeg.
「PG」名稱尚待確認；目前啟動器不需要 PostgreSQL，ffprobe 已包含於 FFmpeg。

02 · Input 放入素材

Create one folder per project, and put your video, photos, and matching subtitles together.
每個專案使用一個資料夾，影片、照片與同名字幕放在一起。

1_input/                 ← Input 素材入口
  我的影片/
    01.mp4
    01.srt
    02.jpg
2_processing/            ← Processing 中間處理資料
3_output/                ← Output 完成成果

The editor can also load a folder you select. It supports video and JPG/PNG photos; convert HEIC first.
編輯器也能載入手動選取的資料夾；支援影片與 JPG／PNG，HEIC 請先轉檔。

Use the current pipeline's numbered folders; input/output are not automatic watch folders.
現有流程以帶編號的資料夾為準；input／output 並非自動監看入口。

03 · AI 分析與製作

Give your AI agent a project folder and a clear request, for example:
告訴 AI 專案資料夾與製作需求，例如：

請處理 1_input／我的影片 的素材。先列出素材內容與字幕處理建議，保留原始檔案；需要 Groq 外部語音辨識時先讓我確認，再開始製作，將完成影片與 SRT 存到 3_output，最後告訴我如何在編輯器修改。

For local editing, double-click the launcher. For this HTML batch editor with transcription and rendering, run the legacy batch mode:
桌面編輯請雙擊啟動器；要讓 HTML 批次編輯器具備辨識與渲染能力，請在專案目錄執行：

./"AI Video Workflow v7.command" --legacy-batch

Filename sorting does not analyze video images; external transcription requires confirmation.
現有 AI 排序只依檔名，不代表分析過影像；外部語音辨識需確認後才送出。

04 · Output 查看成果

Open the generated project files in 3_output. Check playback, subtitle wording, and timing.
在 3_output 開啟專案成果，檢查影片播放、字幕用字與時間。

Keep the matching SRT and your workspace file for later editing.
保留同名 SRT 與私人工作檔，之後才能繼續編輯。

Offline exports go to your browser's download location, not automatically to 3_output.
離線匯出會存到瀏覽器的下載位置，不會自動寫入 3_output。

05 · Editor 編輯器

Load your video and matching SRT, adjust text and timing in Process, then export again from Output.
載入影片與同名 SRT，在 Process 修改字幕與時間，再到 Output 重新匯出。

Offline mode supports preview, subtitle editing, and SRT export. MP4 rendering and transcription need the local controller.
離線模式可預覽、校對字幕與匯出 SRT；MP4 渲染和語音辨識需本機控制器。

Open Editor 開啟編輯器 →

Save the private workspace from the editor menu before closing; burned-in subtitles are not editable text.
關閉前從編輯器選單保存私人工作檔；已燒在畫面上的字幕無法直接當作文字編輯。
