# Cover Style Guide

Neutral thumbnail direction for technical video content: readable title, one main idea, approved assets, and clear review state.



## Operating Rules / 操作規則

- Keep private media, secrets, and generated outputs in their approved folders.
- Do not enable network access, API calls, dependency installs, or home skill sync without explicit approval.
- Use `AI_VIDEO_ALLOW_NETWORK=1` and `AI_VIDEO_ALLOW_HOME_SYNC=1` only for one approved command.
- Treat `_pending/archive-local/` as inactive text-only material.

- 私人媒體、secrets 與生成輸出必須放在核准資料夾。
- 未經明確核准，不得啟用網路、API 呼叫、依賴安裝或 home skill 同步。
- `AI_VIDEO_ALLOW_NETWORK=1` 與 `AI_VIDEO_ALLOW_HOME_SYNC=1` 只可用於單次核准命令。
- `_pending/archive-local/` 視為非作用中文本封存材料。
